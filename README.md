# 🎓 Student Portal

A full-stack Django-based Student Portal developed as part of my M.Tech coursework.  
The application demonstrates Django fundamentals including URL routing, views, templates, template inheritance, models, ORM, migrations, and the Django admin panel.

## 🌐 Live Demo

🔗 **[Visit Student Portal](https://student-portal-django-ekfo-ten.vercel.app/)**

## 📌 Features

- 🏠 Home page with available courses
- 👨‍🎓 Student profile section
- 📚 Course management
- 📞 Contact page
- 🔐 Django Admin panel
- 🗄️ PostgreSQL database using Neon
- 🎨 Responsive glassmorphism-based UI
- 🖼️ Custom Student Portal branding and logo
- 🔗 Student LinkedIn profile links
- ⚙️ Django ORM for database operations

## 🛠️ Technologies Used

- **Python**
- **Django 6.1.1**
- **HTML5**
- **CSS3**
- **JavaScript**
- **PostgreSQL**
- **Neon**
- **Vercel**
- **Git & GitHub**
